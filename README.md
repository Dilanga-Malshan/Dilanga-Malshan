## About

I build AI-powered applications, backend APIs, and web experiences, with a focus on solving practical problems through reliable software. Based in **Sri Lanka** 🇱🇰.

- **AI engineering** — LLM applications, AI agents, and structured outputs with LangChain and LangGraph.
- **Backend development** — APIs and data workflows with FastAPI, Pydantic, SQLAlchemy, and PostgreSQL.
- **Web & mobile** — Angular and TypeScript applications, with an interest in Flutter.
- **Code quality** — Testing and maintainable Python with pytest and Ruff.
